# Campus Cable Planner (Web Frontend + C++ Terminal Application)

This project consists of two parts:
1. **Interactive Web UI**: Built with HTML, CSS, and JavaScript. This provides a visual interface for network structure visualization (Demo version).
2. **C++ Terminal Application**: Contains the complete logical implementation of Dijkstra's algorithm, BFS/DFS algorithms, cable failure simulation, technician dispatching, and bandwidth traffic control.

## How to use the Web UI
1. Double-click the `index.html` file to open it in your browser.
2. Login with the demo credentials (Username: **FUBAO**, Password: **FUBAO123**).
3. The UI will show the dashboard and visual representations of the data structure.

## How to run the complete C++ Logic
To run the full backend algorithms for shortest paths, dispatch simulation, and traffic handling:
1. Open your terminal or command prompt.
2. Compile the C++ program:
   ```bash
   g++ main.cpp -o cableplanner
   ```
3. Run the compiled application:
   ```bash
   ./cableplanner
   ```
